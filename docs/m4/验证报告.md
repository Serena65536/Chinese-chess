## 二、这一版加了什么

**1. 服务端独立 exe**

```
dist\一起来下棋-服务端\一起来下棋-服务端.exe     19.4 MB
```

- 只带 aiohttp + 棋规，**完全不含 Qt**，所以只有 19 MB（客户端 136 MB 主要差在 Qt 运行库）
- 双击即开，控制台会打印局域网地址、计时口径、防火墙提示
- 头像和日志落在 exe 旁边的 `server_data\`，用户可以整个文件夹搬走
- 命令行参数照旧：`--port`、`--base-minutes`、`--byo-seconds`、`--data-dir`

**2. 安装包与安装脚本**

这台机器上没有 NSIS / Inno Setup（只有 7-Zip，而它的 SFX 不支持解压后执行脚本），
所以做成了「压缩包 + 安装脚本」：解压 → 双击 `安装.cmd`，效果和安装程序一样，而且用户能看见脚本在做什么。

`安装.cmd` 做的事：复制到 `%LOCALAPPDATA%\Programs\一起来下棋` → 建桌面/开始菜单快捷方式（客户端 + 服务端）→
写卸载脚本 → 问要不要立即启动。支持 `/silent` 无人值守。

`卸载.cmd`：删快捷方式 → 问要不要连设置和头像一起删 → 自删除并清空程序目录。

**3. 首启动引导**

第一次打开（还没有配置文件时）弹三步说明：先自己下一盘 / 想联机得先有服务端 / 界面怎么个性化。
老用户升级不会被打扰。

**4. 日志**

- 客户端：`%APPDATA%\一起来下棋\logs\client.log`（512KB 滚动 ×3）+ `client-crash.log`（faulthandler，硬崩溃也有栈）
- 服务端：`server_data\logs\server.log`，记录建房/加入/开局/结束；aiohttp 访问日志压到 WARNING 免得刷屏
- 菜单「帮助 → 打开日志目录」，点一下就到

**5. 版本号**

`client/version.py` 一处定义 `1.4.0`，窗口标题、关于页、安装包命名都用它。

## 五、踩坑

| # | 现象 | 根因 | 处理 |
|---|---|---|---|
| 1 | 安装脚本在 `/silent` 下卡死 | 结尾的 `pause` 在无人值守时等按键 | silent 模式直接 `exit /b`，跳过所有 pause/timeout |
| 2 | 快捷方式明明没建成，却提示"已创建" | PowerShell 的 `$sc.Save()` 失败只是写 stderr，脚本继续跑 | 每个快捷方式单独 try/catch，最后汇总提示哪几个失败，并返回非 0 |
| 3 | 发布包里混进了 `selftest.png` / `selftest.log` | 打包时直接 copy onedir，把自检产物也带上了 | `ignore_patterns("selftest.*", "*.log", "server_data")` |
| 4 | 控制台打印 ✅ 报 GBK 编码错 | 中文控制台是 936，emoji 不在字符集里 | 自检脚本改用 `[OK]/[FAIL]` |
| 5 | 测试互相污染配置 | UI 测试写进了回退配置目录，配置测试又读到它 | 测试统一用独立的 `YQLXQ_CONFIG_DIR` |
| 6 | 打包脚本调用 GUI exe 会挂住自动化 | 该环境下 `Start-Process` 等待窗口程序不稳 | 自检脚本改用 `subprocess.run` 直接等进程退出 |

## 六、已知限制

- **没签名**：exe 未做代码签名，别人第一次运行可能看到 SmartScreen 蓝色提示，点「更多信息 → 仍要运行」即可。
- **不是安装程序 exe**：因为本机没有 NSIS/Inno。要真正的 `setup.exe`，装一个 NSIS（~3MB）我把脚本补上即可。
- **服务端是控制台程序**：双击会开一个黑窗口，这是有意的——要看 IP、看日志、看谁进了房间；关窗口即停服。
- 服务端进程重启会丢房间状态（内存态），对内测足够；要长期在线可以把服务端挂成 Windows 服务。

## 七、追加：异地联机走通了（Cloudflare 隧道）

M4 之后补做的一轮验证——客户端支持 `wss://` 后，用 Cloudflare 临时隧道把本机服务端暴露到公网，
两个客户端走公网地址完成建房/进房/开局/走子：

| 项目 | 实测 |
|---|---|
| 隧道地址 | `https://art-framework-sought-first.trycloudflare.com` |
| HTTPS 健康检查 | 1.3–1.7 秒（含 TLS 握手） |
| wss 客户端连接 | 1.8 秒 |
| 走子往返 | 首步 494 ms，后续平均约 283 ms |
| **打包 exe 的 wss 自检** | 通过（2.2 秒连上并建房） |

同时修了一个**只在非回环地址才暴露**的 bug：Qt 会套用系统代理，
连 `192.168.x.x` / 公网域名时报 `The proxy type is invalid for this operation`，
表现为"怎么都连不上"。现在 WebSocket 和头像下载都显式 `NoProxy`，并加了回归测试。

操作说明见 [异地联机指南](../异地联机-Cloudflare.md)。
