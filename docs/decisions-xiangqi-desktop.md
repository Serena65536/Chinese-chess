## D1 ✅ 目标平台：先只做 Windows，代码保持跨平台可移植

- **结论**：v1.0 只出 Windows 安装包，代码不写死 Windows 专有 API。
- **理由**：打包与测试成本最低；Qt 同一套代码以后出 mac/Linux 版几乎不返工。
- **代价**：mac/Linux 用户暂时用不了。

## D2 ✅ 技术栈：Python + PySide6（Qt6）

> **v0.2 修订**：此条推翻 v0.1 的「Electron + React + TS」。推翻原因不是技术判断失误，而是**前提错误**——v0.1 的前提是"用户对所有候选技术栈都不熟"，实际用户会 Python。

- **结论**：客户端 PySide6 6.11（Qt6，LGPL）；服务端 Python + aiohttp；棋规引擎 `xiangqi_core` 纯 Python 包，两端 import 同一份。打包 PyInstaller(onedir) + NSIS。
- **理由**：
  1. 已会 Python，客户端/服务端/引擎同一门语言，零学习成本；
  2. 引擎一份代码两端共用 → 服务端权威判棋（防改棋）不返工；
  3. `QGraphicsView` 自带缩放、命中检测、补间动画，比手写 Canvas 省事；
  4. 本机已核实 PySide6 6.11 + QtMultimedia/QtWebSockets/QtSvg/QtNetwork + PyInstaller 就位。
- **放弃**：Electron（要学 TS、150MB+）、Tauri（引入 Rust）、Godot（设置页/联机全自造）、.NET（不熟 C#）。
- **代价**：包体 60–150MB、启动 1–2 秒、Qt 默认界面朴素需写 QSS、PyInstaller 有杀软误报概率、漏 Qt 插件会白窗口。

## D3 ✅ 联机：中心服务器 + 6 位房间码，服务端权威；服务器必须可自建

- **结论**：不做 P2P/端口直连作为主路径。服务端是独立程序（单文件 + SQLite），既能本机自建也能上云；客户端有「服务器地址」设置项。
- **理由**：①家用宽带普遍在 NAT 后，只有服务端方案能保证任意网络可连；②顺带解决掉线重连、防改棋、超时判负；③服务端可自建 = 把"要不要买云主机"与架构解耦，先零成本验证。
- **放弃**：WebRTC P2P（国内打洞成功率有限，失败要 TURN，且无第三方仲裁）、端口直连（要求一方有公网 IP）。

## D4 ✅ 个性化可见范围：头像同步给对手，背景图与 BGM 各自本地

- **结论**：头像压成 256×256 WebP（~20KB）上传服务端供对手查看；背景图与 BGM 只在本机生效。
- **理由**：头像体积小、社交价值最高；背景/BGM 体积大、涉及版权。
- **代价**：对手看不到你的背景——可接受。

## D5 ✅ 规则：实用完整版（长捉只提示，不自动判罚）

- **结论**：走法生成、自杀检测、将死/困毙、三次重复（长将方负，否则和）、60 回合自然限着、长将判负；长捉/长打只检测提示。
- **理由**：覆盖 99% 实战；「捉」的判定在亚洲规则里极复杂，自动判罚易误判引发争议，工期 +2~3 周。

## D6 ✅ v1.0 附加功能范围：只做求和/认输 + 计时

- **排除**（留 v1.1+）：聊天、观战、悔棋、棋谱导出、注册账号、好友排行。

## D7 ✅ 程序名：一起来下棋

- **结论**：窗口标题、安装包（`一起来下棋-1.0.0-setup.exe`）、配置目录（`%APPDATA%/一起来下棋/`）统一使用。
- **理由**：用户指定；口语化、适合朋友间传播。

## D8 ✅ 计时：30 分钟保留 + 每步 30 秒读秒，超时判负

- **结论**：真读秒（byo-yomi）。保留时间用尽后，每步限 30 秒，超时立即判负；读秒每步重置、不累积；不走加秒制。
- **理由**：用户指定口径。与"加秒（Fischer）"的关键差异是：读秒不看你的存时，30 秒一步就是硬上限，紧张感强、不可能靠存时间拖长对局。
- **实现要点**：服务端 `time.monotonic()` 权威计时；客户端只做显示插值 + 每 250ms 校正；掉线时**双方时钟暂停**、90 秒宽容期、超时判掉线方负；服务端对落子预留 300ms 网络宽限。
- **v1.0 不做**：加秒、罚时、房主自定义时间（留 v1.1）。

## D9 ✅ 视觉：传统木纹 + 立体棋子

- **结论**：木纹底（程序生成）+ 立体感棋子（径向渐变高光 + 投影），红黑双色，文字优先楷体并带字体回退。
- **理由**：用户指定；与程序名的居家气质匹配，且与用户自选背景图不冲突（背景图铺在棋盘外围，棋盘保持不透明以防棋子对比度不足）。

## 素材与许可口径 ✅

- 棋子/棋盘/图标/音效：程序绘制或 CC0 / 自制，**不从网上抓图**
- 内置 BGM：**一首都不内置**
- 字体：只用系统字体，**不打包字体文件**
- 头像：本地裁剪后上传自己的服务器，界面提示"请使用你有权使用的图片"
- 发布物附 `licenses/`，含 Qt LGPL 声明（PySide6 打包后 Qt 为独立 dll，满足可替换要求）
