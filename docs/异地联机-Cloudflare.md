# 异地联机（Cloudflare 临时隧道）

适用于：**两个人不在同一个局域网**，又不想买云主机。

原理：在你（房主）的电脑上跑一个 Cloudflare 隧道进程，它主动连出去，把本机的
`127.0.0.1:8765` 映射成一个公网 HTTPS 地址。朋友访问这个地址，就等于访问你本机的服务端。
不需要公网 IP、不需要路由器端口映射、证书由 Cloudflare 提供。

---

## 一、准备

| 需要 | 说明 |
|---|---|
| 一台常开的电脑（房主） | 对局期间不能休眠；笔记本记得插电 |
| 我们的客户端 + 服务端 | 安装包里都有 |
| cloudflared | **脚本会自动下载**（约 50MB，只需一次）；下不动就手动下，见"排查" |

---

## 二、三步开一局

**房主：**

1. 打开安装目录 → `服务端` 文件夹 → 双击 **`启动临时公网联机.cmd`**
2. 等 5–10 秒，窗口里会出现一行：

   ```
   https://xxxx-xxxx-xxxx.trycloudflare.com
   ```

   这行就是当前的对局地址（**每次重启都会变**）。

**两边（包括房主自己）：**

3. 打开客户端 → 菜单「联机 → 服务器地址…」→ 粘贴上面的地址 → 一方「创建房间」拿 6 位码 → 另一方「加入房间」输码 → 双方「准备」

客户端会自动识别：`https://…` 走 `wss://…/ws`（443 端口），头像走 `https://…/avatar/…`。
也可以直接填 `wss://xxx.trycloudflare.com`，两种写法等价。

---

## 三、实测数据（本机 → Cloudflare → 本机，2026-11 实测）

| 项目 | 数值 |
|---|---|
| 隧道建立 | 7 秒左右（首次） |
| HTTPS 首次健康检查 | 1.3–1.7 秒（含 TLS 握手） |
| 客户端 wss 连接 | 1.8 秒 |
| 每步棋往返（对手收到） | **约 300–500 ms**（首步 494 ms，后续 11–440 ms 波动） |
| 打包 exe 的 wss 自检 | 通过（2.2 秒内连上并建房） |

结论：**回合制象棋完全够用**（人一步棋通常要想 2–10 秒）。断线会自动重连，不影响对局。

---

## 四、限制（务必知道）

- **地址每次都变**：临时隧道没有固定域名。想固定就用命名隧道（需要自己的域名）。
- **没有可用性保证**：Cloudflare 明确说这属于体验用途，不承诺 SLA；偶尔会断，重启脚本即可（地址会变，要重新发给朋友）。
- **房主电脑必须在线**：关机、休眠、断网，对局就断。断线 90 秒内回来可续。
- **流量绕境外**：国内访问会走香港/日本等节点，延迟 300ms 上下；如果只是下棋，可以接受。
- **不要用来跑对公业务**：这是给朋友间对弈的临时方案。

## 五、排查

**连不上先跑网络自检**（会打印到日志并把结果写文件）：

```powershell
一起来下棋.exe --net-selftest wss://xxxx.trycloudflare.com
```

同目录会生成 `net-selftest.log`，里面写着解析出的地址、连接状态和失败原因。

**常见原因：**

| 现象 | 原因 | 处理 |
|---|---|---|
| 自检报 `连接出错：The proxy type is invalid…` | 旧版本没关系统代理 | 用 1.4.0 及以后版本（已修） |
| 自检一直转圈 | 隧道进程没起来 / 地址过期 | 看 `启动临时公网联机.cmd` 窗口是否还在跑 |
| 能连上但对手进不来 | 房间码不对 / 房间满 | 确认 6 位码；一房两人 |
| 服务端窗口一关就断 | 服务端只在前台运行 | 对局期间别关那个窗口 |

**日志位置**：客户端「帮助 → 打开日志目录」；服务端在 `服务端\server_data\logs\server.log`。

**cloudflared 手动下载**（自动下载失败时）：
<https://github.com/cloudflare/cloudflared/releases/latest> → 选 `cloudflared-windows-amd64.exe` →
改名为 `cloudflared.exe` 放进 `服务端` 文件夹。

---

## 六、安全提醒

- 暴露到公网后，**任何人拿到地址都能建房**。目前服务端没有做频率限制（M4 已知项），
  所以：**不要让地址长期挂着**，下完就关窗口重启一次（地址也会换）。
- 房间码是 6 位数字，理论上可被暴力猜；用完即弃的地址能大幅降低风险。
- 头像接口按 16 位内容哈希取文件，猜不到具体是谁的。
